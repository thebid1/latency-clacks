## Overview

Agent Mesh is a live multi-agent economic simulation where 4 specialized AI agents trade autonomously on a custom Solana AMM, creating emergent market behavior through inter-agent coordination.

This project was submitted for a Solana bounty competition and **placed 25th out of 113 submissions**.

## The Concept

Traditional trading bots operate in isolation. Agent Mesh explores what happens when multiple autonomous agents with different strategies interact in the same market—creating emergent behaviors through:

- **Inter-agent communication** via message bus
- **Dynamic liquidity management** from a central Banker
- **Price action generation** through volatility injection
- **On-chain settlement** with real transaction signatures

## Architecture

## The Agents

### 📈 Arbitrageur Agent
**Strategy:** Price momentum trading  
**Behavior:** Buys dips greater than 0.2%, sells rallies greater than 0.2%

### 📊 Trend Follower Agent  
**Strategy:** Moving average crossover  
**Behavior:** Trades on MA3/MA5 golden/death cross signals

### 💧 Liquidity Provider Agent
**Strategy:** TVL-based liquidity provision  
**Behavior:** Adds liquidity to low-TVL pools for higher fee share

### 🏦 Banker Agent
**Strategy:** Central funding coordinator  
**Behavior:** Monitors all agents, transfers SOL when balance drops below 0.3

## Key Features

- **Autonomous Trading**: Agents scan markets and execute trades independently
- **Encrypted Wallet Management**: AES-256-GCM encryption, agents never handle raw keys
- **Real On-Chain Transactions**: All trades settle on Solana devnet with verifiable signatures
- **Live Dashboard**: Web interface for monitoring agent activity in real-time
- **Volatility Generator**: Creates price movements to give agents trading opportunities

## Technical Highlights

### Custom Solana AMM Program
- Deployed Rust program on devnet
- Constant product formula (x times y equals k)
- PDA-based vaults for token custody
- Slippage protection built-in

### Security-First Wallet Design

Agents request operations, WalletManager handles signing:

```typescript
const signature = await walletManager.signAndSend(
  transaction,
  agentName
);
// Private keys encrypted at rest, decrypted on-demand
```

### Message Bus Architecture
Agents communicate via HTTP polling to coordinate:
- Liquidity requests to Banker
- Market state broadcasts
- Transaction confirmations
